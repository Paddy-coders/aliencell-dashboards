Common Q&A
Problem
	
Solution
Which parameter is required to query carriers.
	
A non-empty two-letter country code in `country` is required.


Can carriers be queried for different countries.
	
Yes, change `country` to query the carrier list for the corresponding country.


Is the carrier result paginated.
	
The current implementation returns the carrier list without pagination parameters.
