API Description
Collapse
This API provides JD POP order list query functionality, supporting SOP order type. It adopts an optional field mechanism, and the caller needs to explicitly specify the field names to be returned.
Notes
1. The field names to be returned must be explicitly specified;
2. Self-operated order query is not supported;
Prerequisites
3. Authorization is required to call this API;
Terminology
4. Root parent order rootOrderId: An order can be split into multiple levels, and the parent-child order relationship after splitting forms a tree structure, where the root node of the tree is the root parent order no;
5. Direct parent order no parentOrderId: The parent node of a certain node is the direct parent order no;
6. Order type orderType: The classification identifier of orders by business model;
7. Order flag orderFlag: A more fine-grained classification identifier than order type, an order may have multiple flags;

How is the order list paginated.
	
`page` must be between 1 and 300, and `pageSize` must be between 1 and 100.


What are the time range restrictions.
	
Both start and end times are required, the start must precede the end, and the range cannot exceed three months.


How are multiple order statuses specified.
	
Provide comma-separated values such as `UN_PAID`, `SUSPEND`, `UN_SHIPPED`, `SHIPPED`, `COMPLETED`, `CANCELLED`, `LOCKED`, and `UNKNOWN`.
