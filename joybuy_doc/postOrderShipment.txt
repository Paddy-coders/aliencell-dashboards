API Description
Collapse
support FBM order outbound
Notes
1.the carrier range available for shipment at the site must be obtained from GET sp-order/v0/carrier;
2.the number of shipment waybills must not exceed the quantity of items, and splitting one item into multiple packages for shipment is not supported;
3.only FBM (fulfill by merchant) order outbound is supported, FBJ outbound is not supported;
4.currently only whole-order shipment is supported, split-batch shipment is not supported;

Common Q&A
Problem
	
Solution
Which orders support shipment confirmation.
	
The current domain implementation supports FBM orders only and returns an error when the order does not exist or is not FBM.


Which shipment type is currently supported.
	
Only `shipmentType=1`, full-order multi-package shipment, is currently supported.


Which package and item fields are required.
	
Each package requires carrier ID, carrier name, waybill code, and item details; each item requires SKU UUID, SKU ID, and a quantity greater than zero.
