Common Q&A
Problem
	
Solution
What does isEnableSiteCode do?
	
Controls whether to filter shops by site code from context.


How does the API identify the caller?
	
Reads venderId/venderCode from JSF context, injected by platform.


Does venderId need to be passed by caller?
	
No, it is a system parameter injected by platform.


Is data a paginated structure?
	
No, data is a List, not paginated.


What values does shopStatus have?
	
Returned by downstream, 1 typically means active.
