按日期×国家产品行数均摊)−VAT(仅欧洲与英国)−FBA退货处理费−退款净额−头程(成本表预估)−测评费+其他渠道剔除加回；毛利率=毛利÷利润报表销售额；数据源=易仓「财务-营收利润→利润报表(ASIN)」结算口径（费用按结算日期归属，日视图存在跨天归集；结算数据滞后 1~2 天由自动化回填修订；数据自 2026-07 起）；不含税费/其他交易费；有销量但成本为 0 的行（成本未配置）会使毛利偏高。VAT（2026-10-10 新增）：易仓利润报表的「产品税」与「亚马逊代扣代缴税款」正好互相抵消（净额 0）⇒ 报表没把 VAT 从毛利里扣掉，看板按 (利润报表销售额 − 促销折扣) × 税率 手动扣减（即「销售价 − 优惠价」后的价格为基数）；税率见 `vat_rates.json`（UK 20%、DE 19%、FR 20%、IT 22%、ES 21%、NL/BE 21%、IE/PL 23%、SE 25%），非欧洲站点为 0。若确认报表销售额已是不含税口径而无需再扣，把该文件税率置 0 重跑构建即可。广告费归属：优先取条目自带 ASIN，其次活动名里的 ASIN（运营给广告标题加上 ASIN 码后自动按该 ASIN 归属）；品牌推广（SB）报表不含 ASIN，按活动名的「系列+瓦数」兜底，且按站点区分（同一 SKU 在北美与欧洲是不同 ASIN）。若归属到的 ASIN 在该站点没有利润报表行，该笔广告费仍计入「广告花费」列与合计行的毛利扣减，但该 ASIN 行自身的毛利显示 —。销售店铺：默认合并看（Aliencell官方店铺 = 本看板原有亚马逊数据 + Woot店铺 = 由「Woot 数据管理」页注入的行），可单独筛；Woot 行只有订单/销售额/广告，在易仓利润报表里没有对应行，因此其毛利不走易仓口径，改按下方 Woot 毛利公式单独计算。Woot 毛利口径（采购价 × Woot订单量 − 产品成本 − 头程 − Woot广告费）；成本与头程优先取「Woot 数据管理 → 💵 Woot 成本设置」里逐 ASIN 的手工配置，未配置时自动回退「产品关系管理」——按 ASIN 匹配到的产品名取产品成本表的采购成本与 US 头程，÷ 当月 CNY/USD 折成 USD/台；两处都取不到则该 ASIN 不入毛利（显示 —，避免按 0 成本算虚高）。费用占比列（2026-10-10 新增）：成本%=商品成本÷报表销售额；FBA / FBA% =配送费；promotion / promotion% =促销折扣；仓储 / 仓储% =FBA 仓储费；头程 / 头程% =头程费用；其他费用 / 其他费用% =推广服务费+服务费；VAT / VAT% =增值税（仅欧洲与英国）。占比分母统一为利润报表销售额，除成本外其他费用同时列出绝对值（取正数显示）。头程取产品成本表「头程费用/RMB × 利润报表销量 ÷ 当月 CNY 汇率」，目前为预估值，后续以实际推移头程替换；成本表未覆盖的 ASIN/站点头程按 0 计。尾程（海外仓尾程配送）仅 FBM 订单计入，FBA 订单不计——本看板店铺均走 FBA，故不入成本口径。FBA 库存费 8 细项 / 退款（2026-10-12 第二轮新增）：易仓利润报表的「FBA库存与入境服务费汇总」已按官方公式拆成 8 项单列 —— FBA退货处理费、其他FBA库存和入境服务费、超量费、合仓费、合作承运费、移除费用、FBA月仓租费、FBA长期仓租费（该汇总里还有一项「FBA物流国际货运费」，与「头程」是同一笔成本的两个来源，按确认口径既不展示也不计入毛利）。入账规则：FBA退货处理费、仓储费（=FBA月仓租费+FBA长期仓租费，即「仓储」列）独立计入毛利；其余 5 项（其他FBA库存和入境服务费 / 超量费 / 合仓费 / 合作承运费 / 移除费用）合并进「其他费用」一起分摊计入毛利 —— 所以那 5 列是「其他费用」的明细，不要与「其他费用」相加。库存费全部按 月×ASIN×站点×店铺 的日行数均摊（列合计 = ERP 月度值）。退款：新增「退款金额 / 促销折扣退款 / 销售佣金退款 / 退款净额 / 退款率」——毛利减去退款金额与买家运费退款，加回促销折扣退款、销售佣金退款与配送费退款（按易仓原始符号直接相加，「退款净额」列即这些项的绝对值合计）；退款率 = 退款件数 ÷ 利润报表销量（与易仓界面一致的数量口径）。毛利(RMB)「毛利」列前一列：把显示币种毛利折成人民币，汇率 = CNY/USD × USD/显示币种，与看板其余折算同源（每月 1 号 ECB）。毛利列币种：未选国家或多国混合时按 USD 显示；筛选到的国家同属一种币种（如单选 US、或多选欧盟国）时按当地货币显示。入境货运费 / 多渠道 / 测评费 / 其他渠道剔除（2026-10-12 第一轮）：①「多渠道销量 / 多渠道损失」（及明细列的 多渠道产品成本 / 头程 / 配送费）= 多渠道（MCF）订单的销量与损失，损失 = 产品成本 + 头程 + 配送费；这三项本来就含在商品成本与配送费里（ERP 公式：fbaFeesTotal 含多渠道配送费、productCostTotal 含多渠道订单采购成本与头程），故单独列示而不重复扣减。②「测评费」由「财务数据录入」页按月导入（月份+站点+ASIN+金额+币种），按销量占比摊到行并计入毛利。③「其他渠道已剔除」= 你在录入页导入的其他渠道订单（月份+ASIN+数量）所对应的多渠道成本，已按数量比例从亚马逊毛利中移出（作为加回项）。
